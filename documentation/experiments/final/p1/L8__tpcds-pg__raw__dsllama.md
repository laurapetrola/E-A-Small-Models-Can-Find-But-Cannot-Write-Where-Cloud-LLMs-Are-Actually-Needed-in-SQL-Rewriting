The panel contains, without having been designed for it, a **controlled distillation pair**: the same
procedure (R1 distilled onto an 8B model) applied to **two different bases**.

|---|---|---|---|

**Distilling R1 onto Qwen produces the BEST model in the panel; onto Llama, the WORST.** The same
procedure, opposite results. **Forbidden sentence:** *"models with distilled reasoning write
better"* — the pair disproves it. **Allowed sentence:** *"the gain from reasoning distillation is
conditioned on the base; in our panel it helped on Qwen and hurt on Llama."*

**Honest scope:** there are **two** bases and a single distillation procedure, at n=3. This is an
**observed pair**, not a distillation study. Report it as an observation the matrix allows to be
made — never as a law.

**Never compare `≥X%` with `X%`** — they are not the same ruler.
