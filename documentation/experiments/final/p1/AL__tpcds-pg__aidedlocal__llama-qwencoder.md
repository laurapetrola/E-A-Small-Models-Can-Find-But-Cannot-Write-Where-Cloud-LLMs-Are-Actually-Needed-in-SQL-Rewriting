## Methodological defenses

- **Zero timeouts in 105 runs.** No query was left without data, and n=5 is real across all 21 — it's
  the cleanest cell in the panel on this front.
- **q1 and q30 are `prov.`** — the original doesn't complete at real scale; the gain is a **lower
  bound** and equivalence fell back to SF1, which refutes but doesn't certify. Never compare
  `≥95.8%` with a measured `%`.
- **q85 gave `eq` in all 5 runs** — the writer produced SQL that runs but changes the result. It's the
  second wall, distinct from `mf`: here it writes, but writes wrong.
- **Writer and window declared:** `qwen2.5-coder:7b`, 28/07 → 10/08. Long window (13 days) — the
  comparison with L4 is valid because the writer is **local** and doesn't drift; the same argument
  would **not** hold for a cloud cell.
